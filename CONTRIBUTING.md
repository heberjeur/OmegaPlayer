# Contributing to OmegaPlayer

First off, thank you for considering contributing to OmegaPlayer!

## How to Contribute
1. Fork the repository and create your branch from `master`.
2. Ensure your code compiles and passes all Lint and Unit Tests.
3. Keep your PRs small and focused on a single feature or bug fix.
4. Update documentation or comments where necessary.

## Code Style
- We follow standard Kotlin formatting.
- Ensure no hardcoded strings are added (always use `strings.xml`).

By contributing to this project, you agree to abide by the Code of Conduct.
