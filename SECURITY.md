# Security Policy

## Supported Versions
Currently, only the latest release on the `master` branch is supported with security updates.

## Reporting a Vulnerability
If you discover a security vulnerability in OmegaPlayer, please do **NOT** report it by creating a public GitHub issue. 

Instead, please send an email to the repository owner directly or use the GitHub Security Advisory private reporting feature.

We will acknowledge receipt of your vulnerability report and strive to send you regular updates about our progress. If you're interested, we will also mention you as the discoverer in our release notes.
